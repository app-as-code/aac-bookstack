# Icon source

Icons are downloaded from the selfh.st icon collection (repository `selfhst/icons`,
served via jsdelivr). No icon was drawn or modified by hand.

| File in this repo | Upstream file | Used for |
|---|---|---|
| `icon.svg` | `svg/bookstack.svg` | Default (fallback) |
| `icon-light.svg` | `svg/bookstack-dark.svg` | Blue logo for light color schemes |
| `icon-dark.svg` | `svg/bookstack-light.svg` | White logo for dark color schemes |

Download URLs:

- https://cdn.jsdelivr.net/gh/selfhst/icons/svg/bookstack.svg
- https://cdn.jsdelivr.net/gh/selfhst/icons/svg/bookstack-dark.svg
- https://cdn.jsdelivr.net/gh/selfhst/icons/svg/bookstack-light.svg

The selfh.st family was used for all three files so that the light and dark variants
match the default logo. The homarr-labs/dashboard-icons entry for BookStack has no
light/dark variants and uses a different artwork.
